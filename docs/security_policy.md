# Security Policy

## Passwords

Employees must use unique passwords for all company systems. Passwords must not be reused across personal and work accounts.

Password managers are approved and recommended.

## Multi-factor authentication

Multi-factor authentication is required for email, VPN, code repositories, cloud infrastructure, HR systems, and finance systems.

Employees must never approve MFA prompts they did not initiate.

## Phishing

If an employee receives a suspicious email, they should:

1. Do not click links or open attachments.
2. Use the Report Phishing button in the email client.
3. Forward the message to security@acme.example if the report button is unavailable.
4. Delete the email only after reporting it.

## Data classification

Acme uses three data classification levels:

- Public: approved for public sharing
- Internal: company-only information
- Restricted: sensitive business, employee, customer, or security information

Restricted data must not be stored in personal cloud drives or sent through personal email accounts.

## Device security

All company laptops must use disk encryption, screen lock, antivirus protection, and automatic security updates.
