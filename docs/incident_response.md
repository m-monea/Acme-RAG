# Security Incident Response

## What counts as a security incident

A security incident may include:

- Lost or stolen laptop
- Suspicious login notification
- Malware alert
- Accidental sharing of restricted data
- Suspected phishing attack
- Unauthorized access to company tools
- Exposed API key or password

## Immediate actions

Employees should report suspected security incidents immediately to security@acme.example.

If a device is lost or stolen, employees should also contact IT support at it-support@acme.example.

## Do not investigate alone

Employees should not attempt to delete evidence, contact attackers, or investigate suspicious systems without guidance from the Security team.

## Incident information to provide

When reporting an incident, include:

1. What happened
2. When it happened
3. Which systems or data may be affected
4. Screenshots or email headers if available
5. Any actions already taken

## Response ownership

The Security team coordinates incident response. IT, Legal, HR, and Communications may be involved depending on the impact.
